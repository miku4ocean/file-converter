📋 實作步驟

下載 LibreOffice Online WASM

從 Collabora 獲取預編譯的 WebAssembly 版本：

# 下載 LibreOffice Online WebAssembly wget https://github.com/CollaboraOnline/online/releases/latest/download/loolwsd-wasm.tar.gz # 解壓到你的網站目錄 tar -xzf loolwsd-wasm.tar.gz -C /path/to/your/website/
📂 GitHub 專案

設置網站檔案

將以下檔案加入你的網站：

your-website/ ├── lool/ │ ├── loolwsd.wasm │ ├── loolwsd.js │ └── loolwsd.data ├── convert.html └── app.js

建立轉換介面

建立一個簡單的HTML介面：

<!DOCTYPE html> <html> <head> <title>LibreOffice 線上轉換</title> <script src="lool/loolwsd.js"></script> </head> <body> <input type="file" id="fileInput" accept=".docx,.pptx"> <button onclick="convertToPDF()">轉換為PDF</button> <script> async function convertToPDF() { const file = document.getElementById('fileInput').files[0]; if (!file) return; // 使用 LibreOffice WASM 轉換 const pdfData = await LibreOffice.convertToPDF(file); // 下載結果 const blob = new Blob([pdfData], {type: 'application/pdf'}); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = file.name.replace(/\.[^.]+$/, '.pdf'); a.click(); } </script> </body> </html>

處理 CORS 和檔案權限

確保你的伺服器設定允許 WebAssembly：

# Apache .htaccess <Files "*.wasm"> Header set Content-Type "application/wasm" </Files> # Nginx location ~ \.wasm$ { add_header Content-Type application/wasm; }
