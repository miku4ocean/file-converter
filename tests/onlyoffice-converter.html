📄 OnlyOffice 免費轉檔方案

✅ 可行的免費方案

OnlyOffice Document Server 提供完全免費的JavaScript API：

  • ✅ 完全免費（開源）
  • ✅ 不需要用戶安裝Office
  • ✅ 純瀏覽器運行
  • ✅ 支援PPTX、DOCX轉PDF
  • ✅ 保留完整格式和圖片

⚠️ 設定要求

需要設置OnlyOffice Document Server（可以用Docker輕鬆部署）

🚀 部署步驟：

# 1. 使用Docker部署OnlyOffice (免費)
docker run -i -t -d -p 80:80 onlyoffice/documentserver

# 2. 在你的網站中加入OnlyOffice API
<script type="text/javascript" src="http://your-server/web-apps/apps/api/documents/api.js"></script>
