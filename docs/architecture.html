File Converter.

ARCHITECTURE — 架構圖（依實讀程式碼與 HANDOFF／AGENTS／README 產出）

本工具無後端／無後台：純前端單頁工具，一支 index.html 靠 JS 狀態機切換四種轉換模式。下列五層由「頁面」到「執行期外部依賴」，由上而下依實際資料流排列。

⑤ 外部函式庫（CDN，執行期才動態載入，非隨包／非離線）

必要：jszip ・ jspdf ・ sheetjs

來源：cdn.jsdelivr.net ／ cdn.sheetjs.com

缺一即無法完成對應轉換

可選：mammoth ・ pptxgenjs ・ html2canvas ・ pdfjs-dist

背景載入，逾時／失敗不阻斷核心功能

⚠ 與 AGENTS.md 目標的落差（未確認開發者是否已知）
