MOCKUP 總覽 — 前台線框稿（依實際 index.html／app.js 結構產出）

後台／管理頁面

本工具無後端／無後台。 依 HANDOFF.md、AGENTS.md、README.md 與程式碼實讀：這是一個純前端單頁工具（無 npm 建置、無伺服器、無資料庫、無登入機制），所有轉換運算都在使用者瀏覽器本機完成。因此本 mockup 資料夾不含任何「admin-*」頁面 —— 這不是遺漏，而是真實架構的誠實呈現。

前台頁面（5 個，同一 index.html 內的分頁／狀態）

🖼️ 圖片轉檔
image 分頁 — JPG／PNG／WebP，品質與寬度調整 開啟 → 📄 文書轉檔
document 分頁 — TXT／DOCX／HTML／MD／PDF／RTF 開啟 → 📊 表單轉檔
spreadsheet 分頁 — CSV／XLSX／JSON／HTML 表格 開啟 → 🎯 簡報轉檔
presentation 分頁 — PPTX／HTML／PDF／Markdown 開啟 → ▸ 轉換進度／下載完成
同一單頁內的後段狀態 — build-log 式進度＋下載清單 開啟 →

頁面清單依據

index.html 只有一個實際入口，透過 app.js 的 switchFileType() 在 4 種檔案類型間切換，並用同一組 DOM 區塊（上傳／清單／設定／進度／下載）依狀態顯示或隱藏。本 mockup 依此「4 分頁 ＋ 1 組後段狀態」的真實結構，各拆一頁呈現，未臆造任何路由或頁面。

根目錄 tests/ 下 46 個 test-*／debug-*／final-* HTML 為開發過程產物，HANDOFF.md 明載「勿視為正式功能」，故未納入本 mockup。
